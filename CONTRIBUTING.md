# Contributing

RubixLightingControl is developed incrementally.

## Development principles

- Keep every milestone runnable.
- Prefer modular interfaces over tightly coupled code.
- Avoid hard-coded hardware assumptions.
- Keep network operation local-first.
- Update documentation when behavior changes.
- Test changes before committing them.

## Branches

- `main` — stable releases
- `develop` — integration
- `feature/*` — feature development
