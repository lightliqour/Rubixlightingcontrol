# Raspberry Pi Pico 2 W Node

The Raspberry Pi Pico 2 W is the initial RubixLightingControl node platform.

For the first installation:

- Four Pico 2 W nodes will be used.
- One node will control each LED strip.
- Nodes will connect wirelessly through the local router.
- Internet access is not required for normal operation.

Firmware implementation will begin after the controller-side foundation is established.
