# Hardware

Initial RubixLightingControl hardware:

- Raspberry Pi 4B controller
- Four Raspberry Pi Pico 2 W nodes
- One Pico 2 W per LED strip
- Existing three-wire addressable LED tape

The installed LED chipset is currently unknown.

Planned configurable chipset options include:

- WS2812B
- SK6812
- WS2815
- APA106
- GS8208

Pixel count will be configurable from the controller.
